# 📓 Günlük Takip Sistemi (Daily Record System)

C# ve .NET mimarisi kullanılarak geliştirilmiş, Nesne Yönelimli Programlama (OOP) prensiplerine ve dosya tabanlı veri kalıcılığına dayanan konsol tabanlı bir günlük yönetim uygulamasıdır.

## 🚀 Özellikler

- **Günlük Kaydı Ekleme:** Kullanıcıların tarih ve içerik bilgisiyle yeni günlük notları oluşturmasını sağlar.
- **Kayıtları Listeleme:** Kaydedilen tüm günlükleri ekrana düzenli bir formatta yazdırır.
- **Dosya Tabanlı Kalıcılık (File I/O):** Veriler uygulama kapansa dahi silinmemesi için `gunluk.txt` dosyası üzerinde saklanır ve oradan okunur.
- **Hata Yönetimi (Exception Handling):** `try-catch` blokları ile dosya okuma/yazma süreçlerindeki olası hataların önüne geçilir.

## 🛠️ Kullanılan Teknolojiler

- **Dil:** C#
- **Platform:** .NET / Console Application
- **Kavramlar & Mimari:** 
  - Object-Oriented Programming (OOP)
  - File I/O (`StreamWriter`, `StreamReader`, `File.ReadAllLines`)
  - Error & Exception Handling (`try-catch`)
  - Collections (`List<T>`)
